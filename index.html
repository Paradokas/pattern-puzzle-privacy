Политика конфиденциальности

Приложение «Пазл — Разбери узор» (Puzzle — Unravel the Pattern). Редакция от 24 августа 2026 года.

Настоящая политика описывает, какие данные обрабатываются при использовании мобильного приложения «Пазл — Разбери узор» и веб-версии игры, размещённой на Яндекс Играх.

Какие данные собирает разработчик

Разработчик не собирает, не хранит и не передаёт персональные данные пользователей. В приложении нет регистрации, входа в аккаунт, форм обратной связи и полей для ввода текста.

Данные, которые хранятся на устройстве

Игра сохраняет на самом устройстве прогресс прохождения: номер текущего уровня, выбранный язык и настройки звука и вибрации. Эти данные не покидают устройство и удаляются вместе с приложением.

Данные, которые обрабатывают сторонние сервисы

Для показа рекламы приложение использует Yandex Mobile Ads SDK (ООО «ЯНДЕКС»), в состав которого входит система аналитики AppMetrica. Этот SDK может обрабатывать:

  • рекламный идентификатор устройства (Google Advertising ID или его аналог);
  • сведения об устройстве: модель, версия операционной системы, язык, разрешение экрана;
  • IP-адрес и данные о типе подключения к сети;
  • события показа рекламы и технические сведения о работе приложения.

Данные обрабатываются для подбора и показа рекламных объявлений, оценки их эффективности и защиты от мошенничества. Условия обработки описаны в документах Яндекса: Политика конфиденциальности Яндекса и Политика конфиденциальности в отношении партнёров рекламной сети.

Веб-версия на Яндекс Играх

При запуске игры на площадке Яндекс Игры используется Yandex Games SDK. Он передаёт игре язык интерфейса пользователя и обеспечивает показ рекламы. Обработка данных на площадке регулируется документами Яндекс Игр.

Дети

Игра не предназначена для целенаправленного сбора данных детей и не запрашивает у пользователя никакой личной информации.

Как ограничить сбор данных

Сброс или отключение рекламного идентификатора выполняется в настройках операционной системы устройства: раздел настроек Google или «Конфиденциальность» — «Реклама». Полное удаление приложения стирает все локально сохранённые данные.

Изменения политики

Privacy Policy

Puzzle — Unravel the Pattern application. Last updated: 24 August 2026.

The developer does not collect, store or share any personal data. The game has no sign-up, no account, and no text input fields.

Game progress — current level, chosen language and sound settings — is stored on the device only and is deleted together with the application.

The application uses the Yandex Mobile Ads SDK (including AppMetrica analytics) to display advertising. The SDK may process the device advertising identifier, device model and operating system version, language, screen resolution, IP address, network type and ad impression events. This data is used to select and display ads, measure their performance and prevent fraud. See the Yandex Privacy Policy for details.

On the Yandex Games platform the game additionally uses the Yandex Games SDK, which provides the interface language and handles ad display.

You can reset or disable the advertising identifier in your device settings. Uninstalling the application removes all locally stored data.
